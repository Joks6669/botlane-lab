
# Botlane Lab PWA

Mobile-first duoQ assistant for League of Legends.

## Features
- Riot ID sync
- Duo stats
- Draft assistant
- Matchup recommendations
- PWA installable app
- Mobile dashboard

## Ultra Simple Deploy

1. Create a GitHub account
2. Upload this project
3. Go to Vercel
4. Click "Import Project"
5. Paste environment variables
6. Deploy

## Required Accounts
- Vercel
- Supabase
- Riot Developer Portal

## Environment Variables

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
RIOT_API_KEY=
OPENAI_API_KEY=
YOUTUBE_API_KEY=
```
